ANYFILE

Local file converter with a radial menu for KDE Dolphin.

Install with Discover

Or from a terminal:

flatpak install --user https://pietrolama.github.io/anyfile/io.github.pietrolama.anyfile.flatpakref

Updates arrive through Discover or flatpak update. The KDE runtime is downloaded from Flathub. Then open ANYFILE and press Integrate with Dolphin to add “Convert with ANYFILE” to Dolphin's right-click menu.

The Flatpak does not include LibreOffice, so Word, Excel and PowerPoint documents are not converted. For those, use the .deb package from the releases.
